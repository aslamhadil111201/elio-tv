# ELIO TV v1.9.3-cloud-test7

Prarilis uji tampilan TV + Film.

- Header TV dan Film disatukan: logo, lima menu, jam/tanggal dan penanda pilihan memakai renderer yang sama.
- Skala halaman konsisten; tab kategori Film mengikuti gaya TV.
- Katalog/pencarian gabungan dari provider terpasang, fallback sumber dan konfirmasi jika tahun belum lengkap.
- Ikon i di kartu channel dihapus.

Android 6.0+ untuk IPTV; Android 8.0+ untuk Film. Provider pihak ketiga tidak dibundel. Ketersediaan siaran/provider mengikuti penyedianya.

Build dan 117 pemeriksaan logika lulus. Rendering, sentuhan, remote dan playback di perangkat belum diuji langsung oleh pengembang. Pasang sebagai pembaruan di atas versi sebelumnya.
